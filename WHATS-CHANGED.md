# What's changed

This page lists the changes to BetaNYC's template for Research and Data Assistance Request (RADAR) reports, the starting point the Civic Innovation Lab copies for each new report: new layout features, table options, and setup steps. Newest first. A report made from the template keeps its own list of changes, so if you copy the template, replace this file with your report's history.

- **History begins:** 2026-06-29. The template was first published on this date. Earlier work on it is not listed, and corrections made before it may be missing.
- **Data refresh:** None. The template holds an example report, not live data.

To report a bug in the template, or to ask for a new feature, [open an issue on GitHub](https://github.com/BetaNYC/radar-quarto-template/issues).

## 2026-11-12: New page listing what has changed in the template

- **Tags:** Site
- **What changed:** This page is new, and every report made from the template now starts with one. It lists the changes a reader would notice, and gives a place to say plainly if a report ever publishes a number that turns out to be wrong. A link to it will appear in the footer of every page the next time the site is rebuilt.
- **More detail:** [The change history in this repository](https://github.com/BetaNYC/radar-quarto-template/commits/main)

## 2026-09-15: Setup instructions, an optional database, and a source code link

- **Tags:** Site
- **What changed:** The template now comes with instructions for setting it up and publishing a report, an optional database for reports that use geographic data, and a footer link to the report's source code. The table helper moved into its own file so reports can share it.
- **More detail:** [Issue 3](https://github.com/BetaNYC/radar-quarto-template/issues/3) · [The change](https://github.com/BetaNYC/radar-quarto-template/commit/da7e344)

## 2026-09-10: More control over table layout

- **Tags:** Site
- **What changed:** Tables in the template's style can now have set column widths, a background fill, and a fixed height that shows every row.
- **More detail:** [The change](https://github.com/BetaNYC/radar-quarto-template/commit/bd3a9ff)

## 2026-09-08: Updated table and page style, and a browser tab icon

- **Tags:** Site
- **What changed:** Tables and pages got a round of style updates, and the RADAR mark now shows as the icon in the browser tab.
- **More detail:** [Table and style update](https://github.com/BetaNYC/radar-quarto-template/commit/3c5fa80) · [Browser tab icon](https://github.com/BetaNYC/radar-quarto-template/commit/804ab09)

## 2026-08-07: Section headings restyled

- **Tags:** Site
- **What changed:** Headings in the body of a report got their own style.
- **More detail:** [The change](https://github.com/BetaNYC/radar-quarto-template/commit/7eaaa9c)

## 2026-06-29: The template is published with the Civic Innovation Lab's design

- **Tags:** Site
- **What changed:** The template went online with the Civic Innovation Lab's visual design and an example report showing common report elements, such as charts and tables, and how to style them.
- **More detail:** [Issue 1](https://github.com/BetaNYC/radar-quarto-template/issues/1) · [Pull request 2](https://github.com/BetaNYC/radar-quarto-template/pull/2)
